# Pruebas locales

Estas pruebas verifican las notificaciones de cambio de estado por API y web, y que una imagen se conserve si falla el borrado del registro. Son herramientas de desarrollo y no se requieren para ejecutar la aplicación. Ejecuta `composer test`; si el equipo decide no incluirlas en la entrega, puede retirar esta carpeta y las dependencias Pest de `composer.json` y `composer.lock`.
